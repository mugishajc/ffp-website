# FoodFirst Program website

Website for the FoodFirst Program, an organisation working on sustainable agriculture, nutrition education and community food security in Eastern DR Congo.

## Features

- Sections: hero, about, programs, impact stats with animated counters, testimonials, partners, video and a "get involved" call to action.
- Pages for team, history, annual reports, news and media.
- Donation modal and floating donate button.
- Language switcher.
- SEO meta tags, scroll progress indicator, section reveal animations and back-to-top button.
- Content managed in Sanity CMS: hero, news, media and team members.

## Stack

- React + TypeScript, Vite
- Tailwind CSS, Radix UI primitives
- React Hook Form
- Sanity

## Running

```bash
npm install
npm run dev
```

Sanity schemas are in `sanity/schemas/`.
